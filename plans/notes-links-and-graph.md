# Minc：笔记链接、反向链接与关系图谱

基线：`dev`，`ed0d68ef`；规划时工作树还有未提交的笔记和编辑器改动。开始接入前，确认这些改动已经成为可依赖的基线；不要覆盖、暂存或回退其他工作的文件。本文不改变 `plans/README.md` 中已完成的阶段。

## 目标和范围

用户能从正文打开内链，从目标页回到引用处，再从全库或局部图谱继续浏览。两种语法共用解析和索引，保留 `.md` 源文件；首版不自动重写断链或重命名后的引用，不实现无链接提及、附件节点、标签节点、自动分组和图谱持久化。只为当前本地笔记库建立索引，不改变非笔记工作区、远端文件和已有本地附件的打开方式。

## 1. 提取、解析与打开

- 使用现有 pulldown-cmark 0.13 的 `ENABLE_WIKILINKS` 和 `LinkType::WikiLink`，不要另做全文正则预处理。标准链接和 Wiki 链接保留来源范围和语法种类；代码、图片和属性块不计作正文链接。接入时让 `winc-preview/src/markdown.rs` 与链接提取共用选项，保留排版文本与源位置映射。
- Markdown 目标相对来源文件路径解析；先切分原始 URI 片段和查询，再百分号解码，确保 `%23`、`%3F` 不被误认为分隔符。支持文内标题和跨文件标题，路径不转小写、不靠标题猜测。
- Wiki 裸名按工作区文件名查找，允许省略 `.md`。有同名候选时，以来源笔记所在目录为起点，按经最近公共目录到候选目录的步数比较；只有唯一最近者才自动选中。最近距离并列时，点击打开候选列表，反链和图谱不为它猜目标。带目录的 Wiki 目标以库根为基准；显式 `./`、`../` 以来源目录为基准。库外文件不进入索引。
- 在 `winc-app/src/app/preview/markdown/links.rs` 统一预览点击、错误提示和目标分类。复用 `open_markdown_file`、`jump_to_anchor`，保留预览控件自己的命中路径。外部网页文字链接末尾绘制方框右上箭头，跟链接一起命中，不加入源文件、复制内容或编辑光标位置。内链、断链、附件和纯图片链接不显示该图标，避免影响图片居中及缩放把手。沿用正文编辑中 `⌘`（其他平台 `Ctrl`）加点击打开链接的行为。
- 用 `fixtures/` 的临时副本验证普通相对路径、Wiki 别名、重名、空格、中文、`？` 与 `%3F`、标题跳转和保存保真。插入命令默认生成相对 Markdown，不改已有链接写法。

## 2. 笔记库索引与页尾反链

- 工作区层维护每个来源文件的链接范围和解析结果，按目标维护反向引用。初次扫描放到工作线程；文件范围沿用笔记库的筛选规则，参考 `app/workspace/note_search.rs` 的后台读取模式，不使用其截断预览文本建立索引。
- `app/workspace/watch.rs` 的文件变更流程触发更新。普通改动只重读发生变化的来源，随后在后台重建引用关系；文件或同名匹配变化时无需重读其他 Markdown。首版以最近保存内容为准；切库时丢弃旧结果，不能把上一个库的索引显示到新库。
- 有反向链接时才在正文之后展示反链区，共享正文内容宽度和滚动，不进入文档内容。标题「引用此笔记」，显示 `N 篇笔记 · M 处引用`。索引加载时或删除最后一处引用后，不显示区块，也不占高度。按来源归组，每组初始显示一条上下文，展开其余引用；同一段中的两处链接也计两次。点击标题打开文件，点击摘要定位到对应链接；文件版本变化后重新定位，不能用过期范围跳错。
- 验收：A 同时用 `[[B]]` 和 `[B](./B.md)` 链接 B，B 显示 `1 篇笔记 · 2 处引用`。删掉一处并保存后显示一处；删除最后一处后列表为空。增加一份目录副本时，原件和副本的 Wiki 链接各自指向更近的目标；如果出现两个等距目标，不生成反链或图谱边。另测外部编辑、文件移动和切换笔记库。

## 3. 局部关系图谱

- 页尾「查看关系」和笔记标签页右键菜单「查看关系」均可打开局部图谱，以所选笔记为中心，展示一跳入链和出链。没有反链时仍可通过标签页菜单进入。使用索引生成图数据，不再扫描文件。节点是库内笔记；同一有向文件对合为一条边，保留引用数。文内锚点、网页、断链与附件不生成边。孤立笔记可单独打开局部图谱。
- 首版支持平移、缩放、适应画布、单击聚焦高亮，以及双击或 Enter 打开笔记。局部布局固定中心，保留节点位置，避免变更后画布突然跳动。可用键盘聚焦节点，颜色不是唯一的选中提示。
- 验收：A 对 B 引用两次，只画 A → B 一条边；删除一处边保留，删除最后一处边消失。聚焦 B 时高亮相邻关系，按 Enter 打开 B。

## 4. 全库关系图谱

- 从侧栏打开独立标签页；复用局部图谱的视图、命中和导航。搜索标题并聚焦节点；同名结果显示目录。默认隐藏孤立笔记，可切换显示。缩小时减少标签，选中、悬停或放大时显示更多；不能让长标题遮住主要结构。
- 全库布局后台计算：按连通分量分组，组内以高连接节点为中心排环。不引入力导布局依赖。缩放与平移不重新布局；文件对没变时复用原布局，拓扑变化后重新排布并保留相机位置。
- 分别用约 100 和 1,000 篇生成笔记记录首帧时间和交互表现。验收重点是切库时不显示旧数据、快速缩放不阻塞编辑输入、标签密集时仍能搜索并打开指定笔记；测量后再定性能预算。

## 验证与交付

- 解析层：`cargo test -p winc-preview --locked note_links`。覆盖 Wiki 别名、标准引用链接、重复引用、Unicode、CRLF、代码及媒体排除。
- 应用层：给解析、索引更新和图投影加隔离测试，运行 `cargo test -p winc-app --locked`。每一阶段先通过测试，再接下一阶段。
- 完整检查：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo test --workspace --locked --no-fail-fast`。macOS 用 `python3 scripts/dev.py --once` 打开 Minc Dev，按上面的验收路径测试，只操作临时笔记库。
- 性能样本：`cargo test --locked -p winc-app measure_notebook_graph -- --ignored --nocapture`。在本机调试构建，100 / 1,000 篇生成笔记的索引约 8 / 100 ms；缩放加两次离屏绘制平均约 11 / 74 ms，经单线绘制优化后测得。100 篇的首次绘制包括冷字体和渲染缓存初始化，不和 1,000 篇的暖态作比较；这些数据不是桌面帧率承诺。
- 离屏流程已覆盖两种语法、同名选择、反链展开和回跳、局部图谱节点打开、全库搜索定位。真实桌面验收仍需用测试库检查触控板、缩放和密集图的可读性。
- 预览、排版和渲染测试通过。当前工作树的全量复验受并行开发中的 JSON 预览接入影响，待该功能可编译后重跑应用及工作区检查。
