# Minc 分步计划

目标：在干净的 Winc 上做本地 Markdown 笔记软件。保留 Winc 的文件树和标签页，写作只用一个可编辑的排版视图。内容一直存成真实目录里的 `.md` 文件，不迁移到专有格式。

| 顺序 | 阶段 | 验收点 | 状态 |
| --- | --- | --- | --- |
| 1 | 新建笔记 | `⌘N` 和 `+` 打开空白排版页；默认文件名带 `.md`；中文输入、撤销、保存和重新打开正常，未保存草稿恢复后仍是笔记。 | 已完成 |
| 2 | 笔记主页 | 侧栏目录菜单中的「主页」打开笔记库根目录；点击目录卡片列出该目录的笔记，点击笔记卡片打开正文；原文件树和标签页仍可用。主页采用纸页式笔记卡片和带叠纸的文件夹卡片，不显示面包屑。 | 已完成 |
| 3 | [笔记链接和反向链接](note-links.md) | 两种链接写法打开同一目标；目标页列出引用者和上下文，点击上下文回到引用位置。 | 首版已实现，待桌面验收 |
| 4 | 减少 IDE 入口 | 从笔记界面收起 Git、终端和代码工具，不影响 Markdown 编辑、文件操作和已有笔记。暂不删除底层模块。 | 待做 |

每步先跑相关测试，再用测试笔记验收。不使用真实笔记做写入测试，不搬入 `writing-workspace` 的整套改动。

## 编辑体验

[编辑体验路线图](001-writing-experience.md) 的四批改动均已实现。粘贴表格续写、段落与围栏边界已有桌面单项验收；长文后台重排、选区与输入已有自动化回归，并记录了单视图性能基线。完整 macOS 连续操作仍待复测。

先做写作中的高频动作，再扩展功能。不引入源码模式：所有修改仍直接写进普通 Markdown 文件。

- [x] 换行：`Enter` 新起段落，连续按下时光标逐行下降，空白笔记也一样；段间、文首和文末的连续空行既能点击定位，也能用方向键逐行走过；`Shift+Enter` 在正文、列表和引用中插入标准 Markdown 硬换行。用临时笔记检查撤销、重做、保存重开和 CRLF。参考 [Typora 的换行说明](https://support.typora.io/Line-Break/)；Minc 不把所有已有的单个换行都强制显示为硬换行。
- [x] 结构边界：退出空任务项后写正文，段落可以合并并撤销，CRLF 不变。`⌘↩` 从已闭合的代码块跳到下方正文；未闭合时不误插段落。正文行首退格回到上一代码块的内容，不停在长围栏符号上。
- [x] 剪贴板：对照 [Typora 的复制与粘贴说明](https://support.typora.io/Copy-and-Paste/)，普通复制提供纯文本和 HTML；「复制为 Markdown」提供 Markdown 文本。网页粘贴优先保留 HTML 表格结构，纯文本粘贴不转换。测试覆盖剪贴板两种格式、只有 HTML 的表格、撤销与保存后的文件内容。
- [x] 光标与长文：自动化覆盖跨段选区、中文上屏、连续提交、撤销恢复反向选区，以及后台解析完成时不抢回手动滚开的视口。缓存空行字节位置后，约 1 MiB 混合样本的离屏远跳中位数由约 243 ms 降到 91 ms；大文档输入首帧仍可能有可感知的停顿。
- [x] 页面与格式：收窄正文默认宽度，只保留一级标题横线；行内格式入口只在支持的范围可用，斜杠命令可整步撤销。保留单一排版视图。
- 桌面对照：系统剪贴板验证了 `⌘C`、`⌥⇧⌘C` 和网页表格粘贴。只复制粗体中的一个字时，Minc 的 HTML 原本丢了粗体，修后复测与 Typora 一致。两者 `⇧↩` 都在当前段内换行；Typora 写单个换行，Minc 写标准硬换行。使用相同 HTML 表格剪贴板时，两者都写入 Markdown 表格；Minc 保留单元格换行。修正后，Minc 文末粘贴表格时把光标放在表格下方，直接中文上屏可继续写正文。

## 笔记属性

- 正文顶部显示可折叠的属性面板。没有属性时，右键正文 →「添加属性」；已有属性时，面板底部有添加入口。点字段名打开设置，点值在原处编辑。
- 内置文本、数字、复选框、日期、网址、文本列表、单选和多选。复选框直接切换；日期可手输或用日历选，文件仍保存 `YYYY-MM-DD`；单选、多选用彩色标签，可搜索、切换和新建选项。文本列表可用逗号分隔，单项含逗号时用 `["A, B", "C"]`。
- 值只存原 `.md` 的 YAML；类型和选项存本机的笔记库设置。支持只读参考 `.obsidian/types.json` 中可识别的类型，不执行插件。复杂属性或不安全的改动不重写原文。暂不做数据库、公式、汇总、协作类型。

## 笔记侧栏

未打开文件夹时，侧栏显示打开文件夹和最近目录。打开后，顶部显示目录名、搜索和文件树选项，下面直接显示当前文件夹的内容。点击目录名可切换工作区，底部的「新建文件」在当前目录根目录创建 Markdown 笔记。⌘P 可搜索笔记标题和正文并预览结果。

## 本地验收（macOS）

在仓库根目录运行 `python3 scripts/dev.py`。它会打开固定的 `target/minc-dev/Minc Dev.app`。修改 Markdown 时，应用会照常实时刷新；修改 Rust、界面文案或构建资源时，脚本会自动编译，成功后正常退出并重开同一个测试应用，恢复上次会话。编译失败会保留旧窗口，有未保存的内容也不会强制关闭。`Ctrl+C` 只停止监听；只想构建并打开一次时用 `python3 scripts/dev.py --once`。

仓库不附带测试笔记库。首次启动可以手动打开一个验收目录；如果本机已有 `target/minc-dev/Quiet.md 基准笔记库/`，脚本在没有会话时仍可打开它，不会复制或覆盖其中的文件。测试配置和会话单独放在 `target/minc-dev/home/`，不会使用正式版的资料。
